# 训练方法与验证记录

kai-writing 以参考论文的正文表述为对照，通过正文复现、逐段比较和反复试写训练写作规范。参考论文共200篇，中文、英文各100篇，训练按任务选取其中的章节或段落。每轮记录现有规范未能解决的问题，更新规则和对照例，再用新的材料检验。

## 训练方法

复现前先提取信息骨架，保留研究对象、数据口径、数字、引用、论证关系与必要条件。写作模型只接收骨架和当前规范，据此复现正文。随后将复现稿与原文逐段对齐，检查信息是否齐全、判断是否改变，以及术语归属、语气和段落组织的差异。骨架有缺漏时，先修正骨架，再判断复现稿中的问题。

差异记录按论文去重。多篇论文中重复出现的问题形成候选规则，局部改法保留适用说明。对照例呈现具体的修改方式，文字规则说明证据和论证如何安排。候选规则进入新一轮试写，比较原有问题是否减少、修改是否带来新的问题，据此决定保留、修订或撤回。对照分析同时核对原文中事实、解释和推测的区别，正式评估材料与开发材料分开管理。

## 训练与验证记录

初始复现试验覆盖6篇论文，每篇选取引言、结果与讨论，共18个正常章节单元，另设5个乱序对照单元。逐段比较形成988条记录，其中950条标为差异。86个段落位置涉及信息不对称，相关差异未直接作为表达问题的证据。该轮形成来自3篇论文的3组中文结果段对照，支持一项规则更新。

后续试写扩展到其他章节和模拟任务，检查无据收尾、术语归属、重复解释与素材取舍等问题。部分试写减少了无用收尾和双语释义，不同任务中的改善仍有差异。当前版本合并中文与英文模式，涵盖段落组织、篇幅保留、三线表、人称及标点要求，新增规则的独立效果评估尚未全部完成。公开包中的原创教学例与README中的编辑演示用于说明具体改法。

机械检查用于发现部分字面问题、漏段和修改记录不一致。内容审阅逐段核对事实、判断与证据的对应关系，并检查阅读是否连贯。早期自然度评分存在可靠性问题，效果结论不采用这部分评分。
